# MONEY TRAKER

A personal expense tracker with separate dashboards, monthly expenses, salary and income, EMI tracking, and spending charts in Indian rupees.

## Open the website

1. Click **Code → Download ZIP**.
2. Extract the ZIP completely.
3. Double-click **index.html** and open it in Chrome, Edge, or Firefox.

The HTML includes all JavaScript, CSS, and fonts. No installation, build step, or server is needed. For web hosting, upload `index.html` to any static host.

[Live website](https://money-traker-pratip.mossysalamander.chatgpt.site/)

## Features

- Separate people and year/month selection
- Income, salary, editable expenses, automatic balances
- Multiple EMI plans with payment tracking and undo
- Copy previous-month expenses with duplicate prevention
- Spending chart, search, and category filters
- JSON backup export and restore
- Clash Display numbers, Montserrat text, and responsive layout

## Your records

Data stays in your browser's local storage. This repository contains no personal financial records. To bring records from the live site into this downloaded copy, use **Export backup** on the live site and **Restore backup** in the downloaded copy. Keep the same browser and file location, and export backups regularly.
